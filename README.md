# Hidden Unity Prototype

This repository preserves the original Unity prototype for **Hidden**, a small
blind-board strategy game that mixes tic-tac-toe, battleship, and
rock-paper-scissors.

The maintained web edition lives in
[`PhilHo-Projects/Hidden`](https://github.com/PhilHo-Projects/Hidden) and is
available at [`hidden.philippeho.dev`](https://hidden.philippeho.dev).

## Open the prototype

The Unity project is in `Client/` and was last opened with Unity `6000.3.8f1`.
Open that directory from Unity Hub.

This repository is an archived reference. It contains no multiplayer server or
deployment automation.
